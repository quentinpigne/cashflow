# Données de démonstration

Fichiers **entièrement fictifs** (CLAUDE.md, invariant 7), utilisés avec le jeu de démonstration
(`cashflow demo`, ADR-0018) et par les tests de bout en bout.

- `releve-courant.csv` : relevé du « Compte courant » de démonstration pour octobre 2026, au format du
  profil « Banque démo (CSV) » : colonnes Date ; Libellé ; Débit ; Crédit. La ligne du loyer correspond
  à une transaction déjà saisie (pointage, IMP-05) ; celle de Netflix déclenche la règle de démonstration.
