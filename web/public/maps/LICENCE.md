# Fond de carte des départements

`departements.json` : départements de France métropolitaine, contours simplifiés (coordonnées arrondies au
millième de degré), dérivés de [france-geojson](https://github.com/gregoiredavid/france-geojson)
(`departements-version-simplifiee.geojson`), lui-même issu d'IGN Admin Express.

Licence : [Licence ouverte d'Etalab](https://www.etalab.gouv.fr/licence-ouverte-open-licence). Embarqué dans
l'application pour ne dépendre d'aucun service de cartographie (ADR-0025, R-TIE-29).
